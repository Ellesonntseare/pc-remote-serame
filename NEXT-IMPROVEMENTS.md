# Possible future improvements

Included: smart quality, app switching, resumable uploads, file previews, pinned snippets, PC audio, pointer sizing/lens, guest approval and permissions, guest screen sharing, laser/drawing annotations, touch gestures and Presentation mode.

For a later release:

- Multiple-monitor switching.
- Guest time limits and permission presets.
- Stop all guests with one action.
- Remembered-device management and temporary invite links.
- Chat and shared notes beside screen sharing.
- Connection delay and throughput display.
- Approval for each incoming file.
- Guest-PC control through a separately installed and explicitly approved host. This release shares the guest screen for viewing only.
