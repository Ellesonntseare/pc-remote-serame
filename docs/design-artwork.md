# Reference artwork

The user supplied four visual references. The interface itself is implemented in HTML, CSS, SVG and JavaScript. Two bitmap backgrounds were prepared with the built-in imagegen tool from those references, then exported to WebP for the app. These are scene illustrations, not screenshots of the user's live PC. No external UI template was used.

- `public/workspace-scene.webp`: 1536 × 1024, about 175 KiB.
- `public/login-scene.webp`: 1000 × 1250, about 100 KiB.

Detailed realistic materials and restrained cinematic lighting matching the reference exactly. This is a production background asset for a responsive app. No interface, no text, no badges, no logos, no border, no phone frame. Produce one landscape image.
