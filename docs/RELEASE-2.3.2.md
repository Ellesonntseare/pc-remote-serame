# Elleson Connect 2.3.2 — Trackpad fix

Mouse mode now opens with the trackpad visible. Returning from keyboard mode restores the trackpad automatically. The single floating mode icon continues to expand into the other three mode choices and remains draggable.

Includes the 2.3.1 Windows Explorer appearance, newest-added file ordering, orange liquid navigation, Text & links fix and removal of visible transfer queues.

Install the Windows host update and update Android over the existing personal app. The Android application ID and signing certificate are unchanged. The native Android behavior is unchanged from 2.3.1; the trackpad correction is served by the host.
