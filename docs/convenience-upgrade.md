- [ ] Discover the local PC from Android without entering an IP address.
- [ ] Probe hardware H.264 encoders and retain the working software fallback.
- [ ] Offer focused shortcuts for the active PC application.
- [ ] Add Android launcher shortcuts and a home-screen widget.
- [ ] Preserve Files location, selection and scroll; preserve the remote view across feature pages.
- [ ] Keep the tapped PC field visible above the phone keyboard.
- [ ] Browse Desktop, Documents, Downloads and host-selected folders.
- [ ] Add selection, rename, move, sorting and recursive folder search in Files.
- [ ] Send files and links conveniently in both directions, including Windows Explorer Send To.
- [ ] Configure incremental phone-folder backups and scheduled execution.
- [ ] Route phone audio to a Windows virtual microphone when its audio driver is installed.
- [ ] Run automated, Windows native and browser checks; build the personal APK and installer.

Virtual microphone support requires an installed Windows virtual audio device. The app must distinguish a usable microphone route from ordinary speaker playback and explain the one-time driver setup. Android discovery, widgets and scheduled folder access require the updated APK; browser-only clients retain the existing local address connection.
