# Elleson Connect 2.3.1

- Restored the Windows Explorer appearance in Files, including folder tabs, the sidebar, address bar and detail columns.
- Files starts with newest-added items first and maintains the order on refresh. Creation time is used where available, with modification time as a fallback.
- The floating Remote menu shows one active-mode icon. Tap it for the other three choices, or drag it to move it. The position is remembered.
- Added an orange liquid wave and arrival ripple to the bottom navigation. Reduced-motion and Lightweight appearance settings suppress the animation.
- Removed visible transfer queue panels while transfers and current-progress reporting continue.
- Fixed Text & links panel switching and the return to Files.

Install both packages: the Windows host serves the updated interface and sorting data; the Android APK updates the installed app version. Install the APK over the existing personal app without uninstalling. The application identity and signing certificate are retained.

The second-screen feature from 2.3.0 is retained and still needs its supported Windows virtual-display driver. Actual Android touch dragging, keyboard behavior and driver-dependent display extension require an on-device check.
