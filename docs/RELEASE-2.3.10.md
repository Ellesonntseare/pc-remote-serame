# Elleson Connect 2.3.10 Personal Preview

One Elleson Connect Android app includes PC remote control, file transfers and sync, Second screen, phone screen sharing and approved PC control of the phone, camera and microphone sharing, phone audio, the Elleson Keyboard and automatic fingerprint sign-in. It keeps the regular app package za.co.pcremote.controller and the existing signing certificate. There is no separate Phone Access APK or build flavor.

The existing verified in-app updater and Android installer handoff are included. Android still asks for permission/consent when required, and accessibility and keyboard services must be enabled by the user before use. The combined app declares the permissions needed for these features; this release does not claim banking-app compatibility or bank approval.

The mouse panel has a larger drag handle and visible Width and Height controls. Explicit sizing overrides phone landscape layout constraints and is remembered on the device. Fullscreen touch handlers leave these controls available.

Windows and Android share version 2.3.10. Install the APK over the regular Elleson Connect app to retain its settings and fingerprint setup. If the old separate Phone Access app is also installed, it remains a separate historical installation and is not needed for the combined app; it is not automatically removed.
