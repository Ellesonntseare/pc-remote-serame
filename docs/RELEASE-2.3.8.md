# Elleson Connect 2.3.8 Personal Preview

Windows and Android now share version 2.3.8 on main. This integrates all previously uncommitted November work, the connection recovery and biometric Android updates, and the latest remote-control fixes.

- Connection health and verified local/website route recovery retain remembered owner sessions and resumable transfers.
- Fingerprint sign-in, standard Android permissions and the separate optional Phone Access edition retain their existing package and signing identities.
- Files, live Explorer, transfers, shared sync, Socials integration, navigation and the redesigned Settings, Audio and Second screen interfaces are included.
- Privacy capture/cursor handling, Second screen placement/alignment and touch/keyboard behavior are included.
- Hardware typing starts directly, keyboard controls preserve fullscreen, and the trackpad can be resized and moved while retaining the floating mode selector.

The full Windows installer bundles the tray, desktop agent, Node runtime, production dependencies and complete interface. The Android standard APK updates the regular app; Phone Access remains a separately installable optional edition. Install over the current apps to retain their settings.

Automated build and test results are recorded with the release. Physical phone gestures, biometric sensor behavior, real display placement and live network-change transfer recovery still need device checks.
