# Personal 2.1.4 — Files and account workspace

Files now follows the layout of the Windows Explorer screenshots supplied on 28 October: folder tabs, Back/Forward/Up, breadcrumbs and folder search, a compact command bar, a left navigation tree, Details columns, collapsible date groups, drive capacity and a status bar. The website keeps its existing colours. Phone layouts scroll the file columns inside the workspace. Windows supplies file thumbnails and associated icons where available.

Your host discovers Windows known folders, OneDrive, Shell Home folders, configured folders and ready drives. It does not relocate your files. Folder links and unsupported locations retain the existing access rules. Rename, move, create folder, select, download, upload, view and sorting actions remain connected to the real file manager. Full Windows copy/cut/paste, Recycle Bin and Windows property dialogs are future additions.

Your configured main Google account and local owner-password sign-in use one account workspace. Other Google accounts have separate data. Open **History → View all** or **Settings → Privacy → Account workspace → Account history**. Search activity and full copied text, filter by type/device, load older events, expand text and pin or reuse it. Existing saved snippets are imported once with their original times; repeated imports are deduplicated.

The account retains recorded sign-ins, remote/session actions, approved guest actions on your PC, transfers, folder/file changes, app preferences, shared links/text, clipboard activity, screenshots/recording preparation and supported feature activity. Session chat messages and note/checklist snapshots remain in account history after their live guest session ends; voice and whiteboard actions retain activity metadata. Audio/video recordings and whiteboard pictures are not automatically uploaded into history. Files view, sorting, favourites, tabs, folder selection/scroll position and Text & links drafts follow the account. Live transfer progress and folder-sync definitions are shared as metadata. Restoring state never replays keyboard/mouse input, starts capture or starts duplicate transfers.

PC clipboard text is captured through Windows clipboard change notifications. File-copy and image-copy events retain metadata; this update does not copy image bytes from every clipboard format. The capture switch is in Account workspace settings. Android clipboard changes are available while the app/platform permits access. Browser clipboard access still depends on permission. Native background transfers continue on their originating device; another device receives progress/history, not that device's private Android document permissions or transfer handles. Other apps' private data, operating-system accounts and unsupported network devices cannot be made identical by PC Remote.

History is kept in a private SQLite database on your PC, with indexed search, paginated previews and full text loaded on demand. Connected pages wait for changes rather than downloading the whole history repeatedly. Offline edits remain on their device and retry after reconnecting. A newly connected device's default values cannot overwrite an existing workspace. Your PC must be running and reachable for devices to exchange updates.

Use Node **22.13 or newer** when running source. The Windows installer includes a compatible runtime. Keep `.account-workspace.sqlite` and its SQLite sidecars private alongside your other host data. Shut the host down before copying these files for a manual backup. Existing recorded data remains; events that happened before recording was implemented cannot be reconstructed.

Install the signed personal 2.1.4 APK over the existing personal APK to receive native transfer correlation changes. Website layout/account features come from the updated PC host. Physical Android checks still needed: background completion, notification Pause/Cancel, Home-button floating mode, real IME typing and camera/audio permissions. Automated tests and browser/native Windows checks do not replace those device checks.
