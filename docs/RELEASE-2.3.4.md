# Elleson Connect Android 2.3.4

The Android shell now applies the actual system bar, display cutout and keyboard insets around its content. Headers, Explorer tabs and bottom controls fit within the phone's usable screen; the web interface continues adapting to the available width and height.

The standard edition retains the original package and signing identity, release signing, disabled debugging and the restricted permission set introduced in 2.3.3. Optional phone access remains a separate package. Android updates are downloaded through the authenticated host's verified file transfer path and installed by opening the saved APK in Android Files.

The companion Windows host supplies live PC Explorer, private upload receipts, quiet privacy covers and the refreshed interface. These host features are updated independently of the APK.

Build validation and signing checks do not establish physical phone layout or banking-app acceptance; those require checks on a device.
