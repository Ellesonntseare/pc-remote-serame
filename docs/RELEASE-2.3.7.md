# Elleson Connect Android 2.3.7

Use Connection health in Settings → Connection & devices or from Home. When the host cannot be opened, use Check connection on the Android connection screen.

With a current Windows host and a remembered owner sign-in, Android can switch between the website and local Wi-Fi. Android verifies that the alternate route belongs to the same PC before moving the session. Resumable Android transfers use their existing progress when a verified route takes over. You can turn automatic switching off in Connection health.

The updated host also provides a destination picker for folders starred in Files, alerts when Privacy mode ends, PC restart monitoring, Second screen alignment, and additional shortcuts for Windows apps. The APK uses the same package identity and signing certificate as 2.3.6.
