# Changes on top of Elleson Connect 2.3.0

- Restored the earlier Windows Explorer layout in Files: folder tabs, navigation and address bar, command bar, folder sidebar, detail columns, view choices and status bar. Existing file-manager nodes and handlers stay attached. Restored loading of `explorer-workspace.css` and excluded Explorer from the newer page skin.
- The remote floating menu shows the current mode only. Tap it to reveal the other three choices; choosing one collapses it. Drag the current icon to reposition it. The position is saved locally and constrained to the visible screen, clear of main navigation. Arrow keys also move it; Escape and outside taps dismiss choices. Opening and closing typing updates its icon.
- Files defaults to Newest added, descending, including files and folders together. Browse and search return the filesystem creation date separately from modification date. Where creation time is unavailable, modification time is the fallback. Older saved alphabetical defaults are migrated; explicit sorting choices in this version remain available. Refreshes and incoming transfers reapply the current ordering without clearing selection.
- Removed the visible native transfer queue, dashboard queue card and browser batch list. The transfer engine, notifications and current-transfer progress continue operating.
- Fixed Text & links panel switching: hidden Files panels now override their flex layout. Text mode exposes a Files tab for returning to Explorer and starts at the top of the page.

Validation: the complete suite passed 396/396 after the initial Explorer/menu work. After the subsequent sorting, queue and Text & links changes, 42 focused account, file API, transfer, clipboard/link, file-manager, Explorer, navigation and floating-menu checks passed. Browser review used sample files in an isolated local preview and verified the restored Explorer layout, newest-added selection, collapsed/expanded/keyboard modes, and Text & links visibility with its return to Files. Physical Android touch/drag and IME checks remain to be performed. These changes have not been published or deployed to the running host.
