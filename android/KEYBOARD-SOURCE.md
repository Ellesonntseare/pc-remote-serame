# Elleson Keyboard integration

The existing Elleson Keyboard source belongs to this user and comes from [Ellesonntseare/my-keyboard](https://github.com/Ellesonntseare/my-keyboard), source tree 3bf50df599783ab1b9c95158db034d2e0aa61813. Its Kotlin service, preferences and settings are embedded under za.co.pcremote.controller.keyboard so the Elleson Connect APK can provide the keyboard and share the same paired connection. The separate Mathapelo keyboard is not part of this integration.

Normal phone typing, layouts, one-handed mode and local clipboard features remain the base for the new PC toolbar, shared clipboard and dictation. Selecting this keyboard is a one-time Android settings action; the app does not change the system default silently.
